## 🔒 Требования к БД

Админ-панель автоматически создает необходимые таблицы:
- `system_logs` - системные логи
- `login_attempts` - попытки входа
- `ip_bans` - забаненные IP
- `settings` - настройки системы
- `user_reports` - жалобы пользователей
- `email_logs` - логи отправки email

**Дополнительные поля для таблицы `users`:**
```sql
ALTER TABLE users ADD COLUMN role VARCHAR(20) DEFAULT 'user' AFTER email;
ALTER TABLE users ADD COLUMN status VARCHAR(20) DEFAULT 'active' AFTER role;
CREATE INDEX idx_user_role ON users(role);
CREATE INDEX idx_user_status ON users(status);
```

## 🛠️ Дополнительные настройки

### Изменение логина/пароля

Отредактируйте `/admin/login.php`:
```php
if ($username === 'your_login' && $password === 'your_password') {
    // ...
}
```

### Добавление двухфакторной авторизации

Добавьте в `auth_check.php` проверку 2FA.

### Email уведомления

В `settings.php` настройте SMTP для отправки уведомлений админам.
