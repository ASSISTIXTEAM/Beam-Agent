# Beam Agent — canonical path

**Only project root going forward:** `C:\Beam-Agent`

- Runnable app: `C:\Beam-Agent\dist\Beam-Agent\`
- Exe: `C:\Beam-Agent\dist\Beam-Agent\Beam Agent.exe` (product filename may keep a space; **folders** do not)
- Silent launch: `C:\Beam-Agent\Start Beam Agent.vbs` or `C:\Beam-Agent\dist\Beam-Agent\Start Beam Agent.vbs`
- Sources / scripts: `C:\Beam-Agent\desktop\`, `C:\Beam-Agent\runtime\`, etc.

Do not use `OneDrive\Documents\Beam Agent`, `%USERPROFILE%\BeamAgent`, or `%LOCALAPPDATA%\Programs\Beam Agent` as the project root anymore.
